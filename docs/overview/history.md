The first ideas for sc-tcg go back to **2011**. Since then the project has gone through several iterations, each one refining what a StarCraft-inspired trading card game should feel like. This page keeps track of that history and of the games that shaped it.

## Timeline

| Period | Milestone |
| --- | --- |
| 2011 | First ideas for a StarCraft-flavored TCG |
| 2011 – present | Several iterations; early game-design problems worked through over time — some of them solved in parallel by the excellent game designers at WotC, with sincere thanks to them 🙏 |
| 2026 | The project gets a public home: this site and its documentation structure |

> *Draft — milestones are sparse for now; entries will be added as they are written up.*

## Influences

* **StarCraft (1998), StarCraft II & Brood War** — faction identity (Terran / Zerg / Protoss), unit roles, micro vs. macro tension: the strategic fantasy sc-tcg wants to recreate on a tabletop scale.
* **Magic: The Gathering** — card text as rules language, cost curves, deck-building depth and the ecosystem of interacting abilities.

How each influence is actually used in the design is discussed per topic in [Design Principles](../design/design-principles.html) and [Card Types](../rules/card-types.html). For what the game is today, see [About the Game](about-the-game.html).
