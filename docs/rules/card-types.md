A deck in sc-tcg is built from a small set of card types. Each type has a clear role during play, and every type will get its own detailed article once it is fully defined — this page keeps the index and the current draft state.

## The card types (draft)

| Type | Role in play | Status |
| --- | --- | --- |
| **Unit** | Represents a StarCraft-style unit on the field; has stats, can act during the Action phase | Draft — detailed page to come |
| **Ability** | One-shot or repeatable effect played from hand (spells in MTG terms) | Draft — detailed page to come |
| **Support** | Sets up ongoing effects that shape a player's game plan over time | Draft — detailed page to come |

> *Draft — the names and split of types are working hypotheses; expect them to be revised as playtesting happens.*

## How types interact with the rules

* What can be played when is governed by the [turn structure](core-rules.html#turn-structure).
* What a card's text box may contain (costs, keywords, ability lines) is described in [Card Anatomy](../design/card-anatomy.html).
* Why the type split looks like this — and what it borrows from StarCraft vs. Magic: see [Design Principles](../design/design-principles.html).
